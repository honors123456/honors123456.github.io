OpenGL 入门渲染

从创建上下文到绘制三角形，讲解现代 OpenGL 的基础流程。

01

初始化

使用 GLFW、GLUT 或 SDL 创建窗口和 OpenGL 上下文，随后初始化 GLEW/GLAD 或其他加载器。确认启用深度测试与视口设置。

02

缓冲对象

配置 VAO、VBO 和可选的 EBO，将顶点数据上传到 GPU。设置顶点属性指针后，解绑 VAO 以便在渲染时只需绑定它即可。

float vertices[] = {
  0.0f,  0.5f, 0.0f,
  0.5f, -0.5f, 0.0f,
 -0.5f, -0.5f, 0.0f
};

GLuint VBO, VAO;
glGenVertexArrays(1, &VAO);
glGenBuffers(1, &VBO);
glBindVertexArray(VAO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
03

着色器

编写顶点和片元着色器，并在程序对象中链接。渲染循环中绑定着色器并绘制三角形。

GLuint shaderProgram = createShaderProgram(vertexSource, fragmentSource);
glUseProgram(shaderProgram);
glBindVertexArray(VAO);
glDrawArrays(GL_TRIANGLES, 0, 3);
