QML 自定义组件与复用

从设计可复用组件到在不同视图间复用属性与行为，掌握 QML 组件化开发的实战要点。

01

为什么要自定义组件

通过将界面逻辑封装为可组合的组件，能够实现更简洁的布局与更易于维护的项目结构。QML 的组件系统让你可以在多个视图间复用布尔属性、动画状态和交互行为。

02

组件定义与复用

将组件放在单独的 QML 文件中，例如 CustomButton.qml 或 StatusCard.qml，然后在需要的页面中直接引用。这样可以利用属性绑定与信号来实现不同页面间的数据传递。

import QtQuick 2.15
import QtQuick.Controls 2.15

Rectangle {
  id: card
  width: 320
  height: 140
  color: "#ffffff"
  radius: 18
  border.color: "#ddd"

  property alias title: titleText.text
  signal clicked()

  Column {
    anchors.centerIn: parent
    spacing: 10

    Text { id: titleText; font.pixelSize: 18; color: "#333" }
    Button { text: "查看"; onClicked: card.clicked() }
  }
}
03

属性与信号设计

使用 property 和 signal 来定义组件接口，让外部页面可以灵活控制视觉和交互行为。例如，为组件提供标题、图标和点击事件回调。

04

与 C++ 后端连接

如果组件需要复杂业务逻辑，可以将 C++ 对象注册为 QML 类型，或使用上下文属性传递对象引用。这样既能保持 UI 的声明式表达，又能利用 C++ 的性能和扩展能力。
