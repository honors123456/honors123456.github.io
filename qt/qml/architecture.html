QML + C++ 混合架构

展示如何把 QML 声明式界面与 C++ 后端逻辑组合成可维护的应用。

01

架构分层

界面层负责 QML 展示，逻辑层由 C++ 提供，二者通过信号槽、属性绑定和上下文属性协同工作。这样的分层能保证 UI 声明式与业务逻辑解耦。

02

类型注册与上下文属性

通过 qmlRegisterType 注册 C++ 类型，或使用 setContextProperty 传递单例后端对象。注意对象生命周期，通常将其设置为 QQmlApplicationEngine 的父对象。

qmlRegisterType("App", 1, 0, "MyBackend");
engine.rootContext()->setContextProperty("backend", &backend);
engine.load(QUrl("qrc:/main.qml"));
03

属性、信号与绑定

使用 Q_PROPERTY 和 signals 将数据暴露给 QML，保持响应式更新。QML 侧可直接绑定属性并监听信号，实现界面自动刷新。

class MyBackend : public QObject {
  Q_OBJECT
  Q_PROPERTY(QString title READ title NOTIFY titleChanged)
public:
  QString title() const { return m_title; }
signals:
  void titleChanged();
};
04

QML 侧调用

在 QML 中通过上下文属性或已注册类型访问 C++ 对象，调用方法并绑定属性。例如，使用 backend.title 显示文本，或在按钮点击时调用后端方法。
