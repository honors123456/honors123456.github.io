自定义仪表盘控件

通过 QPainter 绘制指针、刻度和渐变背景，实现可交互的控件组件。

01

绘制流程

在 paintEvent 中完成绘制，先平移坐标原点到控件中心，再缩放到比例空间。这样可以用统一坐标绘制仪表盘、刻度、指针和渐变背景。

void GaugeWidget::paintEvent(QPaintEvent *) {
  QPainter painter(this);
  painter.setRenderHint(QPainter::Antialiasing);
  painter.translate(width() / 2, height() / 2);
  painter.scale(radius / 100.0, radius / 100.0);
  // 绘制刻度、指针等
}
02

事件与交互

通过重写鼠标事件响应用户输入，计算角度并更新当前值。配合 QPropertyAnimation 可以让指针移动过程更加平滑。

void GaugeWidget::mousePressEvent(QMouseEvent *event) {
  // 计算新的值并更新
  update();
}
03

尺寸与性能

实现 sizeHint 使布局器更好地安排控件大小。对复杂图形使用缓存 pixmap，避免每次重绘都重复计算。

QSize GaugeWidget::sizeHint() const {
  return QSize(220, 220);
}
