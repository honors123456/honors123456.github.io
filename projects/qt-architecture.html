Qt 项目架构分析

分享 Qt 项目常见目录结构、模块分层和可维护的架构设计。

01

分层结构

建议将项目分为 UI 层、业务层、数据层和资源层，保持职责清晰。UI 层只负责展示，业务层处理核心逻辑，数据层处理输入输出与存储。

02

界面与逻辑分离

使用 QML 或 QWidget 负责展示，用 C++ 负责状态管理与业务逻辑。将信号槽绑定和视图数据分离，方便后续维护与测试。

class AppController : public QObject {
  Q_OBJECT
public:
  Q_INVOKABLE void loadData();
signals:
  void dataReady(const QVariantList &items);
};
03

模块化复用

把通用组件、服务和工具类提取到独立模块，便于复用与测试。使用 CMake 子目录或库项目组织代码，并明确模块间依赖。

add_subdirectory(core)
add_subdirectory(gui)
add_executable(app main.cpp)
target_link_libraries(app PRIVATE core gui)
