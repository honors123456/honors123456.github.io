OpenCV 性能调优

分享减少图像复制、使用并行处理与缓存友好设计的实践方法。

01

避免不必要复制

OpenCV 的 cv::Mat 默认采用引用计数，尽量通过引用或子矩阵避免复制。使用 Mat::colRange、rowRange 等函数可以获取子视图而不拷贝数据。

cv::Mat roi = src(cv::Rect(0, 0, 100, 100));
cv::Mat gray = src;
// 这两者不会马上复制数据
02

并行优化

使用 OpenCV 内部并行框架、OpenMP 或 TBB 来加速循环与滤波。对于自定义算法，可以使用 #pragma omp parallel for 或 parallel_for_。

#pragma omp parallel for
for (int y = 0; y < rows; ++y) {
  // 并行处理每一行
}
03

缓存友好

在处理多通道图像时，按行主顺序访问数据，避免频繁跨行访问。优先使用连续内存布局并减少边界检查开销。

04

性能测量

使用 cv::getTickCount() 衡量关键路径性能，避免只依赖主观体验。

double t0 = cv::getTickCount();
// 运行代码
double t1 = cv::getTickCount();
double elapsed = (t1 - t0) / cv::getTickFrequency();
