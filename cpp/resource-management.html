智能指针与资源管理

深入分析 unique_ptr、shared_ptr、weak_ptr 与资源管理模式，避免内存泄漏与悬挂引用。

01

unique_ptr

唯一所有权，适合管理单个动态对象或数组。

std::unique_ptr ptr = std::make_unique(args);
ptr->doSomething();
02

shared_ptr

引用计数共享所有权，适合多个模块共同使用同一资源。

auto shared = std::make_shared(args);
auto copy = shared; // 引用计数 +1
03

weak_ptr

避免循环引用，可用于缓存、观察者模式与临时访问。

std::weak_ptr observe = shared;
if (auto alive = observe.lock()) {
  alive->doSomething();
}
04

实践建议

优先使用 unique_ptr，只有真正需要共享所有权时才使用 shared_ptr；weak_ptr 用于打破循环引用。
