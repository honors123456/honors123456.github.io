模板元编程基础

通过类型萃取、条件编译和 constexpr，在编译期构建更灵活可复用的泛型组件。

01

type traits

使用标准库 traits 可以在编译期检测类型特征并进行分支选择。

template
void process(T&& value) {
  if constexpr (std::is_integral_v>) {
    // 整数专用逻辑
  } else {
    // 其他类型逻辑
  }
}
02

constexpr

constexpr 让函数和变量在编译期求值，从而产生零开销抽象。

constexpr int factorial(int n) {
  return n <= 1 ? 1 : n * factorial(n - 1);
}
static_assert(factorial(5) == 120);
03

概念与约束

Concepts 提供语义化的模板约束，提升报错可读性。

template
concept Arithmetic = std::is_arithmetic_v;

template
T add(T a, T b) {
  return a + b;
}
04

实战应用

用模板元编程构建 Traits、Policy、可配置容器和编译期静态映射，提升库的泛化能力。
