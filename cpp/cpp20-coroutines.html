C++20 协程入门与实践

从协程模型、常见关键字，到简单调度器的实现，帮助你把异步代码写成更直观的同步风格。

01

协程基础

协程是可暂停和恢复的函数。co_await、co_yield 和 co_return 定义了控制流的切换点。

C++20 协程本身是语言特性，具体行为由 promise 类型与 awaiter 决定。

02

关键语法

co_await等待异步结果，并在需要时将控制权交给调用者。
co_yield产生中间结果，并保留当前状态。
co_return结束协程并返回最终值。
03

示例代码

struct Task {
  struct promise_type {
    Task get_return_object() noexcept { return {}; }
    std::suspend_never initial_suspend() noexcept { return {}; }
    std::suspend_never final_suspend() noexcept { return {}; }
    void return_void() noexcept {}
    void unhandled_exception() { std::terminate(); }
  };
};

Task example() {
  std::cout << "开始协程\n";
  co_await std::suspend_always{};
  std::cout << "协程恢复\n";
}

以上示例演示协程分成两个阶段，先进入挂起状态，然后由外部恢复。

04

实践建议

在网络 IO、文件读取、事件驱动或并发任务中使用协程，可以减少回调嵌套，提升可读性。

对于工业级项目，建议结合已有框架（如 cppcoro、asio 或 libuv）来管理协程生命周期。
